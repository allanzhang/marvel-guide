# MCU Recap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a static `/recap` story-arc page with validated cross-work event content and links to existing works, characters, and concepts.

**Architecture:** Add a dedicated `content/recap.json` content source, validate it in the existing Node validation script, and render it through focused Astro components. The page remains static and uses no client-side JavaScript.

**Tech Stack:** Astro 5, native CSS, Node.js validation scripts, JSON content files.

## Global Constraints

- Keep zero client-side JavaScript.
- Use existing base path helpers and URL conventions.
- Do not modify existing content models beyond adding `recap.json`.
- Do not invent unreleased film plots; use `upcoming` events only for known threads and open questions.
- All character, concept, and work references must use existing IDs.
